# Video Downloader - تطبيق تنزيل الفيديوهات

تطبيق سطح مكتب متكامل لتنزيل الفيديوهات من يوتيوب والمنصات الأخرى، مبني بأحدث التقنيات.

## 🚀 المميزات

- ✅ **بحث وتحليل**: ابحث عن فيديوهات أو أدخل رابطاً مباشراً
- ✅ **معاينة الفيديو**: شاهد الفيديوهات مباشرة داخل التطبيق
- ✅ **إخفاء الإعلانات**: حظر تلقائي للإعلانات وتجاوز طلبات التسجيل
- ✅ **تنزيلات متعددة**: إدارة عدة تنزيلات في نفس الوقت
- ✅ **تحكم كامل**: إيقاف مؤقت، استئناف، إلغاء للتنزيلات
- ✅ **سرعة حقيقية**: عرض سرعة التحميل الفعلية والوقت المتبقي
- ✅ **جودات متعددة**: اختر من جميع الجودات المتاحة
- ✅ **صوت فقط**: خيار تنزيل الصوت بصيغة MP3
- ✅ **قوائم التشغيل**: دعم كامل لقوائم التشغيل
- ✅ **دعم العربية**: واجهة كاملة باللغة العربية مع دعم RTL

## 🛠️ التقنيات المستخدمة

- **Electron** - إطار عمل تطبيقات سطح المكتب
- **React 18** - مكتبة واجهة المستخدم
- **TypeScript** - لغة البرمجة
- **Tailwind CSS** - إطار عمل CSS
- **Vite** - أداة البناء السريعة
- **electron-vite** - تكامل Vite مع Electron
- **Zustand** - إدارة الحالة
- **yt-dlp** - محرك التنزيل الأساسي
- **ffmpeg** - معالجة الفيديو والصوت

## 📋 المتطلبات

- Node.js 18 أو أحدث
- npm أو yarn
- yt-dlp (سيتم تضمينه تلقائياً)
- ffmpeg (سيتم تضمينه تلقائياً)

## 🚀 التثبيت والتشغيل

### 1. تثبيت الاعتماديات

```bash
cd my-video-downloader
npm install
```

### 2. تشغيل في وضع التطوير

```bash
npm run dev
```

### 3. بناء التطبيق للإنتاج

```bash
npm run build
```

### 4. إنشاء حزمة للتوزيع

```bash
# لجميع المنصات
npm run dist

# أو لمنصة محددة
npm run dist:win    # Windows
npm run dist:mac    # macOS
npm run dist:linux  # Linux
```

## 🔧 إعداد yt-dlp و ffmpeg

### للخيار الأول: التضمين مع التطبيق (موصى به)

قم بتحميل الملفات التنفيذية وضعها في مجلد `resources/bin/`:

- **Windows**: `yt-dlp.exe`, `ffmpeg.exe`
- **macOS/Linux**: `yt-dlp`, `ffmpeg`

روابط التحميل:
- yt-dlp: https://github.com/yt-dlp/yt-dlp/releases
- ffmpeg: https://ffmpeg.org/download.html

### للخيار الثاني: استخدام النسخ المثبتة على النظام

إذا كان yt-dlp و ffmpeg مثبتين على النظام ومتاحين في PATH، سيعمل التطبيق تلقائياً.

## 🎨 الاستخدام

### البحث عن فيديو
1. اكتب كلمات بحث في شريط البحث العلوي
2. اضغط "تحليل / بحث"
3. اختر الفيديو من نتائج البحث

### تنزيل من رابط مباشر
1. انسخ رابط الفيديو من يوتيوب
2. الصق الرابط في شريط البحث
3. اضغط "تحليل / بحث"
4. اختر الجودة المطلوبة
5. اضغط "تنزيل"

### تنزيل قائمة تشغيل
1. الصق رابط قائمة التشغيل
2. سيتم عرض جميع الفيديوهات في القائمة
3. اختر الفيديو المطلوب لتنزيله

### إدارة التنزيلات
- **إيقاف مؤقت**: أوقف التنزيل مؤقتاً
- **استئناف**: أكمل التنزيل المتوقف
- **إلغاء**: ألغِ التنزيل نهائياً
- **فتح الموقع**: افتح مجلد الملف بعد اكتمال التنزيل

5. **التحديثات**: yt-dlp يحتاج للتحديث الدوري لدعم المواقع الجديدة

## 🐛 حل المشاكل

### yt-dlp لا يعمل
- تأكد من أن yt-dlp موجود في `resources/bin/` أو مثبت على النظام
- جرب تحديث yt-dlp: `yt-dlp -U`

### ffmpeg غير موجود
- تأكد من أن ffmpeg موجود في `resources/bin/` أو مثبت على النظام
- على Linux: `sudo apt install ffmpeg`
- على macOS: `brew install ffmpeg`

### التنزيل بطيء
- تحقق من اتصال الإنترنت
- جرب تنزيل بجودة أقل
- تأكد من عدم وجود تنزيلات متعددة في نفس الوقت

### الإعلانات تظهر
- بعض الإعلانات قد تتجاوز الحظر
- التطبيق يستخدم تقنيات متعددة لحجب الإعلانات
